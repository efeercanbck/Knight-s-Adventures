# Knight's Adventures

![Godot Engine](https://img.shields.io/badge/Godot-4.x-blue?logo=godotengine&logoColor=white)
![Language](https://img.shields.io/badge/Language-GDScript-green)

## Key Features & Mechanics

* **Fluid Character Controller:** Custom physics implementation for responsive acceleration, deceleration, and gravity curves.
* **Level Design:** TileMapLayer-based environment featuring layered collision detection and hazard interactions.
* **State Management:** Clean separation of player states (Idle, Run, Jump, Fall) driven by animated sprites and signals.
* **Enemy AI:** Behavior routines featuring distinct patrol routes, player detection, and target chasing.
* **Reward Mechanism:** Dynamic collection loop requiring a threshold of coins to earn a level-clearing star.
* **Self-Contained Executable:** Packaged with embedded `.pck` architecture for seamless distribution.
